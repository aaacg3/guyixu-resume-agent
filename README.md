# 🤖 Resume Agent - 把自己做成一个AI Agent

> 与其在简历上写「熟练使用AI工具」，不如直接做一个AI产品给你看。

## 🎯 这是什么？

这是一个基于RAG（检索增强生成）的AI Agent，它就是我的「数字代言人」。

你可以问它任何关于我的问题——我的经历、我的项目、我的技能、我的优势……它都会基于我的真实信息来回答。

**为什么做这个？**
- 静态的简历太无聊了，每个人都在写"熟练使用AI工具"
- 与其说我懂AI产品，不如直接做一个AI产品给你看
- 交互式的体验比PDF更有记忆点
- 这本身就是我对AI产品落地的一次实践
- 让招聘方能直接感受到我在AI应用方面的动手能力

## ✨ 功能特性

- 💬 **自然对话**：像聊天一样了解我，比看简历有趣多了
- 📚 **基于事实**：所有回答都来自我的真实经历，不瞎编
- 🎯 **精准匹配**：可以针对特定岗位/问题深入了解
- 🌍 **24/7在线**：随时可以问，不用等我回复
- 📱 **即开即用**：网页端直接用，不需要安装任何东西

## 🛠️ 技术架构

```
用户提问 → 语义检索（个人知识库）→ LLM生成回答 → 以第一人称输出
```

- **平台**：Coze/扣子（低代码Agent平台）
- **核心技术**：RAG（检索增强生成）
- **知识库**：简历、项目详情、面试QA、个人信息
- **模型**：豆包大模型

## 💡 产品思考

### 为什么做这个项目？

投递AI产品经理岗位时，我发现一个问题：所有人都在简历上写"熟练使用ChatGPT/豆包"、"对AI产品有热情"，但怎么证明？

说自己懂AI产品，不如直接做一个AI产品出来。于是就有了这个项目——把自己做成一个Agent，让招聘方直接体验。

### 设计思路

1. **定位清晰**：不是做一个万能的AI，而是做一个"关于我的AI"，聚焦在求职场景
2. **体验优先**：零门槛，打开就能用，不需要注册不需要下载
3. **边界明确**：不知道的就说不知道，不瞎编，引导和本人交流
4. **人设统一**：用第一人称回答，就像我本人在和你聊天

### 迭代计划

- [ ] V1.0：基础对话功能，基于知识库回答问题 ✅
- [ ] V1.1：增加语音对话能力
