# 求职方向与职业规划

## 求职意向
- **目标岗位**：AI产品经理 / 产品经理 / 测试开发
- **个人定位**：具备扎实软件工程背景 + AI工具落地实践经验 + 完整产品生命周期参与经验

## 为什么选择AI产品方向
1. **兴趣驱动**：我对AI技术和产品都有浓厚兴趣，AI产品经理是把这两者结合的最佳岗位。我持续关注LLM、AI应用生态的发展，平时也会主动探索各种AI工具。

2. **背景匹配**：软件工程专业背景让我能和研发团队高效沟通，测试工程师的经历让我养成了用户视角和质量意识，这些都是产品方向的重要素质。

3. **实践验证**：在牧原实习期间，我已经在实践用AI工具拆解业务、输出方案、提升效率，这让我确信自己喜欢也适合做AI产品相关的工作。

4. **长期价值**：AI是未来十年最确定的趋势之一，做AI产品既能站在浪潮之巅，又能真正创造用户价值和商业价值。

## 我的核心优势
1. **AI实践经验**：不是只会用AI工具，而是真正在工作中落地AI提效方案，有实际成果
2. **全球化经验**：两段海外项目经验，熟悉跨地域产品适配、多币种交易等场景
3. **全链路产品认知**：深度参与过从需求评审到上线复盘的完整产品流程
4. **技术背景**：软件工程专业，能和研发团队高效沟通
5. **学习能力**：能快速上手全新业务逻辑，适应高强度迭代节奏

## 职业规划
- **短期（1-2年）**：快速成长为一名合格的产品经理，深入理解业务场景下的AI产品落地方法论
- **中期（3-5年）**：能够独立负责一条产品线，从0到1打造有价值的AI产品
- **长期**：成为AI产品领域的专家，用AI技术创造真正的用户价值和商业价值
